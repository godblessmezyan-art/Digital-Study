3. **孤儿 CSS**：`.note-slip`、`.recent-row*` 等（组件已删，样式残留）。
4. **纯装饰性交互未实现**（原型阶段刻意为之，别当 bug 修）：搜索框无过滤、侧栏「读书笔记/收藏/设置」无 target、按钮无 click。
